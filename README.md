# Access Overlay

A universal screen-reader overlay for Windows. Captures any foreground app, website, or game and makes it readable — with NVDA speech, a floating reader window, OCR-based game scanning, and a built-in accessible browser.

## Features

- **App Capture (Ctrl+Alt+A)**: Captures the active foreground window and normalizes UI elements into readable document hierarchy.
- **Game Scan (Ctrl+Alt+G)**: On-screen OCR menu scanning for game engines (Unreal, Frostbite, Source, Unity, etc.).
- **Accessible Web Browser**: Built-in WebView2 browser with article text extraction and automatic read-on-load options.
- **Screen Reader Support**: Integrated with NVDA controller client and Windows Speech API (SAPI).
- **Customizable Overlay Reader**: Floating, customizable window with dynamic font resizing, contrast themes, and opacity control.

## Requirements

- Windows 10/11 (64-bit)
- .NET 8.0 Runtime
- NVDA (optional, for screen reader integration)
